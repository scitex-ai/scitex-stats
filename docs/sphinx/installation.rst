Installation
============

Basic Installation
------------------

.. code-block:: bash

   pip install scitex-stats

Optional Dependencies
---------------------

.. code-block:: bash

   # Base install (MCP server + plotting included)
   pip install scitex-stats

   # With the Statistics GUI app
   pip install scitex-stats[server]

   # Everything
   pip install scitex-stats[all]

Development Installation
------------------------

.. code-block:: bash

   git clone https://github.com/scitex-ai/scitex-stats.git
   cd scitex-stats
   pip install -e ".[dev]"
